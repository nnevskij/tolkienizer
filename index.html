🍺 Homebrew (macOS & Linux)

The swiftest path — recommended for most travellers.

# Add the tap and install
brew tap nnevskij/tap
brew install tolkienizer

# Upgrade in the future
brew update && brew upgrade tolkienizer

🔨 Build from Source

For those who forge their own tools in the fires of craft.

git clone https://github.com/nnevskij/tolkienizer.git
cd tolkienizer

# Interactive installer
./install.sh

# Or standard Makefile
make && make install
