Engineered with Purpose

Native C speed meets authentic high-fantasy lore.

Pure Native C99

No heavy runtimes, no 500MB node_modules, no python virtual environments. Links only against libcurl and cJSON. Instant startup.

Multi-Language Native

English by default, with specialized literary pre-prompts for Italian (Alliata/Fatica register), Spanish, French, German, or auto-detect.

Local & Offline via Ollama

Works 100% locally and offline with Ollama (e.g. llama3). Zero external API requests, zero subscriptions, complete privacy.

Zero Hardcoded Keys

Includes an interactive terminal wizard (tolkienizer --config). Configurations are saved with strict POSIX 0600 file permissions.

UNIX Pipeline Ready

Accepts text via standard input, files (-f), or arguments. Pipe git diffs, commit logs, or server alerts directly into Tolkien prose.

Homebrew Packaging

Installable and upgradeable with standard Homebrew commands on macOS and Linux with automatic dependency resolution.

Get Started in Seconds

Install tolkienizer via your preferred package manager or build from source.

Homebrew (macOS & Linux)

brew tap nnevskij/tap
brew install tolkienizer

From Source (Any UNIX)

git clone https://github.com/nnevskij/tolkienizer.git
cd tolkienizer
make && make install
